# Ola Mundo

Projeto simples em Rust que imprime "Hello, world!" no terminal.

## Requisitos

- Rust e Cargo instalados

## Como executar

```bash
cargo run
```

## Estrutura do projeto

- `Cargo.toml`: configurações do pacote e dependências
- `src/main.rs`: ponto de entrada da aplicação

## Observação

O diretório `target/` foi excluído do controle de versionamento por ser gerado durante a compilação.
